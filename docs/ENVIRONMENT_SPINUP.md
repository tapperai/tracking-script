
## CI detail (moved from CLAUDE.md)
CI: `.github/workflows/tests.yml`, job `Validate template.tpl (pre-deploy gate)` (about 10 s) on every ready PR next to `CI gate` (mode from `CI_GATE_MODE`); `test-batch.yml` batches and bisects; `ci-label.yml` maps the `ci:` labels. The ruleset on `main` is disabled, so a red check does not lock the button: never merge on red. Local command: `node scripts/test-changed.mjs` runs `python3 scripts/validate_template.py template.tpl --metadata metadata.yaml` (needs full git history) and `node scripts/run_template_tests.mjs template.tpl` unless the change is prose only.
Time window (batch): a due batch waits until the newest batch on the branch started `CI_BATCH_MIN_INTERVAL_MIN` (default 60; `0` turns it off) minutes ago, unless `CI_BATCH_MAX` (default 32, equal to the bisect's `BISECT_MAX_MERGES` in `tests.yml`) merges are waiting. The AFFECTED `base` is the newest PASSED `(batch)`, `(batch-affected)` or `(nightly)` run on the branch's first-parent line; a red `batch-affected` run is bisected from its own `base`. Local test (no network, a fake `gh`): `bash .github/scripts/ci/batch-trigger.test.sh`.
Gallery check: read `versions[0].sha` and `permission` from the Gallery API for owner `tapperai`, template `tracking-script` (`https://tagmanager.google.com/api/gallery/owners/tapperai/templates/tracking-script`, drop its first line). `docs/BACKLOG.md` (P0 needs verification) says whether the `tapper.init` permission fix has reached the Gallery.
